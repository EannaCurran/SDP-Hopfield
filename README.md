# Hopfield-SDP
Experiments and program used to generate results for "Effectiveness of SDP rounding using Hopfield Networks"

## Dependencies
cvxpy - 1.3.1
gurobipy - 10.0.1
matplotlib - 3.5.3
networkx - 2.8.8
numpy - 1.23.4
pandas - 1.5.1
scipy - 1.9.3
sklearn - 1.1.3
torch - 1.13.1
tqdm - 4.64.1

## Running Experiments
Each experiment for Cut,Clique and Colouring can be found within the /Experiments folder. To change which graph instance is used the change the 'currentGraphType' variable index to march with 'graphType'.
